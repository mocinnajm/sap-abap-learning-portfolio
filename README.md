# SAP ABAP Learning Portfolio

## About this project

This repository documents my journey learning SAP ABAP through practical exercises and small projects.

I have completed a Higher Technician qualification in Multiplatform Application Development (DAM) and have a programming background in Java and Python. I am now learning SAP ABAP to develop my skills in enterprise software development.

My goal is to understand the fundamentals, write clean code, and build practical projects that demonstrate what I learn.

## Environment and tools

- SAP BTP ABAP Environment (Trial)
- Eclipse IDE
- ABAP Development Tools (ADT)
- Git and GitHub
