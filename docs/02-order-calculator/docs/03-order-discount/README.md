
# Project 03 — Order Discount

## Overview
A simple ABAP application that checks whether an order qualifies for a discount based on its total amount.

## Learning objectives
- Use conditional statements with `IF`, `ELSE` and `ENDIF`.
- Compare values using `>=`.
- Work with `abap_true` and `abap_false`.
- Pass parameters to methods and return results.

## Business rule
Orders with a total amount greater than or equal to 100 qualify for a discount.

## Test cases

| Order total | Expected result |
|---:|---|
| 120 | Discount eligible (`X`) |
| 80 | No discount (initial/empty value) |
| 100 | Discount eligible (`X`) |

## Technologies
- SAP ABAP
- Eclipse ADT
- SAP BTP ABAP Environment
